Fall 2026
Professor: Anwar Mamat (anwar@umd.edu)

Prerequisites: C or better in CMSC216 and CMSC250

Duration: August 31 - December 21

COURSE OVERVIEW
This course prepares students to leverage AI throughout the software development lifecycle. Students will master two critical skills: using AI to supercharge productivity and engineering the next generation of AI-powered software.

LEARNING OUTCOMES
- Apply advanced prompting techniques (k-shot, chain-of-thought, RAG, tool calling)
- Use AI coding assistants for code generation, refactoring, and debugging
- Build and deploy full-stack web applications with modern frameworks
- Implement modular design patterns and object-oriented principles
- Write and evaluate unit, integration, and regression tests
- Use Git for version control and collaborative workflows
- Conduct code reviews and evaluate AI review tools
- Apply UI/UX design principles with AI assistance
- Identify and remediate security vulnerabilities
- Build autonomous coding agents and multi-agent systems
- Deploy applications using Docker and CI/CD pipelines
- Critically assess AI-generated code and understand responsible use

COURSE TOPICS
- Foundations and GenAI landscape
- Version control (Git/GitHub)
- Prompt engineering techniques
- Web frameworks (FastAPI, Flask, Streamlit)
- Testing, TDD, and coverage analysis
- Databases (SQL, BigQuery, PostgreSQL)
- Software architecture and design patterns
- Autonomous agents and Model Context Protocol
- Code review processes
- Security analysis and vulnerability remediation
- Cloud deployment and CI/CD
- Ethical considerations in AI development
